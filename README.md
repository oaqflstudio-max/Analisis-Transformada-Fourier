# Análisis y Simulación de Señales con la Transformada de Fourier

Este repositorio contiene la implementación en Python para el análisis de señales en el dominio del tiempo y de la frecuencia mediante la Transformada Rápida de Fourier (FFT).

## Contenido del Repositorio
- fourier_analysis.py: Código en Python con la generación de señales, cálculo de la FFT y visualización de espectros de magnitud y fase.
- Gráficas generadas para cada señal elemental y sus propiedades.

## Requisitos de Ejecución
Para ejecutar el código se requiere Python 3 y las siguientes librerías:
